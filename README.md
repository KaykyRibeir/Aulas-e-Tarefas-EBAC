
# 📘 Aulas e Tarefas EBAC

Repositório contendo as **aulas, exercícios e tarefas práticas** desenvolvidas durante o curso de **Desenvolvedor Full Stack Python da EBAC**.

---

## 📌 Sobre o projeto

Este repositório reúne diversos exercícios práticos de programação, organizados por arquivos individuais de aula e atividades, com foco em:

* Lógica de programação com Python
* Programação orientada a objetos (POO)
* Manipulação de arquivos e dados
* Introdução a banco de dados
* Desenvolvimento de APIs com FastAPI
* Uso de Docker e ambientes virtualizados
* Boas práticas com Git e GitHub

## ▶️ Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/KaykyRibeir/Aulas-e-Tarefas-EBAC.git
```

### 2. Entrar na pasta

```bash
cd Aulas-e-Tarefas-EBAC
```

---

### 🐍 Com Python

```bash
python main.py
```

---

### 📦 Com Poetry (se instalado)

```bash
poetry install
poetry run python main.py
```

---

### 🐳 Com Docker

```bash
docker compose up --build
```
